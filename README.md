# 김단아 · 게임 기획자 포트폴리오

[포트폴리오 바로 보기](https://dotoridesuyo.github.io/dana-game-portfolio/)

캐릭터·내러티브·콘텐츠 기획 프로젝트 6개를 소개합니다. 시작 인사말과 메인 상단에는 “게임 기획자 김단아입니다”를 표시합니다.

기획 문서, 플레이, 캐릭터 대화와 음악 링크 및 포트폴리오 이미지 18장을 제공합니다. `editor.html`에서 배치를 편집할 수 있으며, 편집 설정은 이 버전 전용 브라우저 저장 공간의 키로 저장됩니다.

HTML/CSS/JavaScript 정적 사이트입니다. 공개 이미지 40개는 `assets.zip`에 있으며 GitHub Actions가 이를 풀어 GitHub Pages에 게시합니다. 인증 키나 별도 비밀 값은 필요하지 않습니다.
